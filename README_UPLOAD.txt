TNS GROUP — ГОТОВЫЙ САЙТ ДЛЯ GITHUB PAGES

Файлы для загрузки в корень репозитория zurabd89.github.io:
- index.html
- styles.css
- script.js
- 404.html
- robots.txt
- sitemap.xml
- папка assets целиком

Как загрузить через браузер GitHub:
1. Откройте репозиторий zurabd89.github.io.
2. Нажмите Add file -> Upload files.
3. Перетащите все файлы и папку assets из этого комплекта.
4. Внизу нажмите Commit changes.
5. Подождите 1-3 минуты и обновите https://zurabd89.github.io/ через Ctrl+F5.

ВАЖНО:
- Адрес info@tns-grp.ru уже указан на сайте, но письма начнут приходить только после настройки корпоративной почты.
- После подключения домена tns-grp.ru метатеги, robots.txt и sitemap.xml уже будут готовы.
- Не загружайте ZIP как один файл: сначала распакуйте архив и загрузите содержимое.


ЯНДЕКС МЕТРИКА
1. Создайте счётчик для tns-grp.ru в Яндекс Метрике.
2. Скопируйте номер счётчика.
3. В script.js замените строку const YANDEX_METRIKA_ID = 0; на ваш номер.
4. После этого статистика будет доступна в кабинете Яндекс Метрики.
